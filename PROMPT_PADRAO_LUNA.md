# PROMPT PADRÃO PARA EXECUTAR UMA MACRO COM O LUNA

Copie este texto e acrescente o conteúdo de `PROJECT_CONTEXT.md` + a macro atual.

```text
Execute somente a macroetapa abaixo.

Regras:
- Leia primeiro PROJECT_CONTEXT.md.
- Faça a menor implementação que satisfaça os critérios de aceite.
- Não implemente etapas futuras.
- Não refatore partes não relacionadas.
- Reutilize arquivos e padrões existentes.
- Evite novas dependências; se forem indispensáveis, explique em 1 frase.
- Faça no máximo 1–3 testes focados, apenas se necessários.
- Não rode suíte completa repetidamente.
- Ao final, informe: arquivos alterados, validação executada e resultado.
- Atualize PROJECT_CONTEXT.md em no máximo 5 bullets.

MACRO ATUAL:
[cole aqui]
```

## Quando houver erro
Envie somente:
- macro atual;
- erro completo;
- arquivo onde ocorreu;
- arquivo diretamente relacionado.

Evite começar uma nova conversa despejando todos os documentos do projeto.
