# Vibecoding

Documentos usados para planejar e executar o desenvolvimento do Chatbot Genérico V1.

- `INDICE.md`: ordem das macroetapas.
- `macroetapas/`: especificação de cada etapa.
- `PROJECT_CONTEXT_TEMPLATE.md`: modelo de contexto para continuidade.
- `PROMPT_PADRAO_LUNA.md`: prompt de execução por macroetapa.

O código da aplicação permanece na raiz do repositório.
