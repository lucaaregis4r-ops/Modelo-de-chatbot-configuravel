# M05 — Tela Criar/Editar Assistente

**Objetivo:** editar a configuração sem mexer no código.

**Tela mínima**
- nome;
- descrição;
- instruções;
- modo (consulta/tutor/avaliação, mesmo que só consulta funcione agora);
- botão salvar/aplicar.

**Fazer**
- formulário simples;
- validação mínima com campos obrigatórios;
- aplicar configuração ao chat.

**Evitar**
- dashboard bonito, permissões, templates complexos.

**Aceite**
- usuário cria configuração e conversa com ela na mesma sessão.

**Validação:** fluxo manual criar → abrir chat → perguntar.
